# Comprehensive codebase audit fixes

Completed 2026-11-26 on baseline `0.4.1` (`0328d6b`). All functional, state-machine, CUA contract, SSH/VPS and test-coverage issues identified across the two-pass audit have been repaired and verified locally on Windows 11 and WSL Ubuntu.

## Key repairs

- **Transaction preflight and recovery safety (`Lifecycle.ps1`, `AgentIntegration.ps1`, `Setup-Tacto.ps1`)**: added `Assert-AgentIntegrationReady` preflight checks before `Start-Transaction` so user-edited Skill or MCP files fail fast without stopping services or leaving a wedged `transaction.json`. Guarded `Restore-Transaction` against client-integration conflicts, bypassed transaction restoration during `Uninstall`, allowed parameter correction after incomplete initial `setup` runs (`preparing`/`connecting`/`failed`), synchronized Windows callback `authorized_keys` across all Remote updates, added share-lock retries to `Write-AtomicJson`, pruned superseded `releases\*` directories beyond active/previous, split interactive `UninstallString` from hidden `QuietUninstallString`, and fixed `Update.cmd` (`-Action Update`) and `Export-McpConfig.ps1` bridge exports.
- **Bridge process isolation, health verification and CUA contract alignment (`Invoke-CuaBridge.ps1`, `Setup-Tacto.ps1`, `McpHealth.ps1`, `src/driver-cli.mjs`, `src/cli.mjs`, `src/probe.mjs`)**: bound spawned Driver processes to a Win32 Job Object (`KILL_ON_JOB_CLOSE`), bounded stdin-EOF shutdown (10 s) and post-exit stream draining (2 s) to prevent inherited-handle deadlocks, capped `cua-cli` stdin at 8 MiB, tracked nested `run_steps` session leases and `end_session` `isError` states, routed Local activation and `check` through `Invoke-CuaBridge.ps1` (`-Local -Health` / `-Local`), added `tools/list` pagination and `-32601` unsupported-method replies, passed `server.command` to `childEnvironment` in `src/probe.mjs`, accepted `--health`/`--smoke` in any position in `tacto-cli probe` while rejecting unknown `-` flags cleanly, supported `--key=value` options, accepted bare `tacto-cli driver <tool>` shorthand while blocking all 22 `cua-driver` management subcommands, pre-checked `--screenshot-out-file` (and intercepted JSON `screenshot_out_file` on remote `--proxy`/`--ssh` CLI calls so screenshots save on the Agent host) while stripping raw base64 payloads from JSON stdout, and wired optional `--permission-mode` (including `--dangerously-bypass-approvals` for `unrestricted`) and `--capability-manifest` (`--approve-capability-manifest`) directly into the `cua-driver serve` Scheduled Task.
- **SSH, auto-update, multi-device and Linux VPS hardening (`Setup-Tacto.ps1`, `Start-Tunnel.ps1`, `Update-Available.ps1`, `scripts/Package.ps1`, `src/integration.mjs`, `src/skills.mjs`, `install/linux/setup-vps.py`)**: promoted pre-installed `Manual` `sshd` services to `Automatic` (restoring prior start type on unshared uninstall), preserved qualified domain/Entra (`azuread\user`) and space-containing Windows usernames, normalized IPv6 VPS addresses, streamed tunnel logs line-by-line using `System32\OpenSSH\ssh.exe`, embedded pinned `known_hosts` lines into offline uninstall receipts for `tacto-cli cleanup`, cleaned up `%TEMP%\.Tacto-temp\elevation-*`, `Package.ps1` staging folders and `Update-Available.ps1` staging archives while verifying GitHub asset digests and skipping background UAC elevation, compared MCP entries canonically (key-order independent without PS 5.1 array unrolling), unified OpenCode Skill discovery (`~/.config/opencode` and `%APPDATA%\opencode`), added `--mcp-name` / `--skill-name` overrides with `customNames` preservation across VPS `configure` updates, and preserved `~/.ssh/authorized_keys` symlinks while isolating corrupted sibling `state.json` files on Linux VPS hosts.
