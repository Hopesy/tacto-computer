# Tacto 0.3.0: CLI and official Skills

User outcome: both native CLI and MCP access to the selected Windows computer, plus release-matched official CUA guidance managed by the existing npm lifecycle.

- Added local, VPS-local and outer-SSH CLI routing, typed JSON stdin, session-aware maintenance and host-side image output.
- Imported the unchanged official 0.46.1 Skill pack with verified archive/file hashes and MIT attribution. A short adapter binds Windows, device, CLI prefix and MCP name.
- Skill discovery is optional; explicit directories and --no-skills are supported. Per-file receipts cover upgrade, rollback, legacy migration and edited-file preservation.
- VPS management protocol 2 streams bounded JSON over stdin. Migration from 0.2.x uses the original VPS login once; the new helper retains the older request format for previous runtimes.
- Kept npm/CLI installation, hidden background tasks and @latest Agent prompts.

Verification: Windows syntax, Node CLI/integration tests, Python CLI/MCP/bridge tests, isolated Windows local/remote lifecycle, ownership/maintenance, Skill migration and full-pack transport checks passed. Linux VPS tests passed under WSL. Native CUA 0.46.1 acceptance in `.Tacto-temp/native-3140bde3e03349c4bd4a06bff87700ff` covered install, cross-process named sessions, busy-update deferral, update, fault recovery, manual rollback, restart, retained reinstall and full uninstall. Native session output reported client_kind=cli, state=active, with no visible cursor. Tests performed no desktop input actions.

The CLI image contract was checked against tagged upstream Rust source (screenshot_png_b64). Fake SSH process tests exercise VPS/outer-SSH quoting and stdin routing; the callback runs the shipped Windows bridge. A fresh external VPS deployment was not part of this local acceptance.

A failing Windows 5.1 transport regression exposed extended Get-Content string properties expanding JSON serialization; plain .NET text reads fixed it. The test now passes with the full official pack and a large Unicode stdin payload.

Final source `edf1e45` passed [Windows and Linux CI](https://github.com/Hopesy/tacto-mcp/actions/runs/43171927260). The final native run also passed in `.Tacto-temp/native-8d539514cbac476ebb6d3cef85dee607`. The CI UTF-8 console regression was reproduced against the previous bridge, then fixed by setting BOM-free input encoding and closing the raw input stream.
